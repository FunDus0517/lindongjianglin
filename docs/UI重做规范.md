# 《凛冬降临》UI 重做规范（依据用户上传的两张设计稿）

> 来源：`93FA8510-….png`（整体布局说明图）、`3941C709-….png`（12 屏 UI kit 拼图）
> 目标：把当前"网页列表式"界面，重做成**手游级 HUD**：等距雪地基地为视觉中心，
> 顶部资源栏 + 左侧图标栏 + 底部导航 + 卡片面板。
> 本文件是执行标准；实现时以本文件为准，不以旧页面结构为准。

## 一、整体框架（自上而下 / 自左而右）

```
┌───────────────────────────────────────────────┐
│ 顶部资源栏：头像+等级+经验条 │ 资源×N │ 时间+天气 │ 设置 │
├──────┬────────────────────────────────────────┤
│左侧栏│                                        │
│ 任务 │            基地主视图（等距雪地）        │
│ 邮件 │        建筑节点 + 名称标签 + 状态        │
│ 好友 │                          ┌──────────┐  │
│ 人物 │                          │建造 队伍  │  │
│ 追踪 │                          │背包 更多  │  │
│ 地图 │                          └──────────┘  │
├──────┴────────────────────────────────────────┤
│ 底部导航：基地 │ 探索 │ 队伍 │ 背包 │ 光脑      │
└───────────────────────────────────────────────┘
```

- **顶部资源栏**：头像 + 昵称 + 等级 + 经验条；资源图标（木材/石材/食物/钢材/晶核…）各带
  数值与 `+` 快捷入口；右侧显示**当前时间与天气温度**、设置齿轮。资源不足时数字标红。
- **左侧图标栏**：任务 / 邮件 / 好友 / 背包 / 队伍 / 光脑 / 设置，**竖排图标 + 小字**，
  点开对应面板（"更多"里放低频入口）。
- **任务追踪**：左栏展开后显示主线/支线任务的实时进度（`4/5`），可一键跳转。
- **小地图**：显示当前区域位置与周边建筑；有"全屏 / 返回"。
- **右下角快捷按钮**：圆形按钮组（建造 / 队伍 / 背包 / 更多），始终悬浮在基地视图之上。
- **底部导航**：基地 / 探索 / 队伍 / 背包 / 光脑 —— 与现有页面映射见第五节。

## 二、视觉规范（苹果风 + 冰雪科幻）

- 底色：深蓝黑（现有 `--bg` 系）；面板为**半透明毛玻璃**，大圆角（卡片 20–24px）。
- 主色：冰蓝 `#4E8DFB`；辅助：暖橙（火焰/供暖）、青绿（产出/满级）、警告红。
- 卡片统一三层：外描边 1px 冷光 + 内部渐变 + 底部投影；毛玻璃必须带 `-webkit-backdrop-filter`（iOS）。
- 数值用**等宽数字**（`font-variant-numeric: tabular-nums`），避免跳动。
- 图标：优先 emoji + CSS，后续可换美术资源；**不引入外部图标库**（保持零依赖）。
- 动效：面板入场 220–280ms 缓出；按钮按下 `scale(.97)`；资源变化数字上浮淡出；
  建筑升级时格子上有进度环/进度条；全部受 `prefers-reduced-motion` 约束。

## 三、关键界面规格

### 1) 基地主视图（核心，替换现在的"基地页列表"）
- 等距雪地场景 + 建筑节点：**指挥中心 / 仓库 / 发电站 / 温室 / 工坊 / 伐木场 / 农田 / 居民楼 / 防爆墙**。
- 每个建筑：图标或小模型 + **名称标签**（深色胶囊底）+ 等级徽标 + 状态点
  （运作中 / 升级中 / 停摆 / 未建成）。
- 点击建筑 → 打开**建筑详情卡**：
  - 名称 + Lv.N + 效果一句话
  - **升级耗时**（`00:04:04` 形式）与**升级需求**逐项对照（`木材 50/50`，不足标红）
  - 主按钮「升级」（材料不足禁用并给原因）+ 次按钮「进入」
- **建造模式**：建筑列表卡（木材工坊 / 石材工坊 / 防爆墙 / 温室…），每张显示消耗与「建造」；
  建造后进入**倒计时状态**（`00:12:30`）并给「加速升级」。

### 2) 背包界面
- 顶部分类：全部 / 资源 / 道具 / 装备 / 材料。
- 物品网格：图标 + 数量角标；底部显示**背包容量 76/100** 与「整理」。
- 批量操作：批量使用 / 一键出售。

### 3) 队伍界面
- 左侧成员列表（头像 + 名字 + 等级），右侧选中成员详情卡：
  立绘 + 名字 + 等级 + **战力数字** + 星级 + 属性（生命/攻击/防御/速度）+ 技能/装备/编队页签。
- 对应游戏内：幸存者（现有 `characters` + 排班分工）；属性映射为
  生命=健康、攻击=战力、防御=防护、速度=效率。

### 4) 探索界面
- 地图上分布**地点节点**（雪原森林 / 废弃镇 / 冰封港口…），点节点 → 地点卡 →「探索」/「返回基地」。
- 对应游戏内：现有五城区地图 + 21 个地点（`systems/Map.js`）。

### 5) 光脑界面
- **科技树节点图**：生存科技 / 能源科技 / 防御科技分支，节点显示等级与解锁线，已解锁点亮、未解锁灰锁。
- 对应游戏内：现有五条科技线（`systems/Tech.js`），需要从列表改成**节点图**。

### 6) 任务 / 成就 / 设置
- 任务：主线（带进度 `4/5` 与奖励图标）+ 支线，行动按钮「前往」。
- 成就：进度条 + `已达成` 按钮（对应现有 `Achievement`）。
- 设置：基础设置滑杆（音乐/音效/震动/画质）+ 账号信息（对应现有 `Settings` 页）。

### 7) 启动页
- 大标题「末日之下 守护希望」+ 副标题「— 冰寒末日生存之旅 —」+「开始游戏」按钮，
  背景为雪原。对应现有 `pages/Home.js`（已有动态雪花，改文案与排版即可）。

## 四、执行顺序（每步都必须保持测试全绿）

1. **外壳先改**：顶部资源栏（图标+数值+时间天气）、底部导航改名、左侧图标栏。
2. **基地主视图**：建筑节点 + 详情卡（升级需求逐项对照 + 倒计时）。
3. **背包 / 队伍 / 光脑**：网格、成员详情、科技树节点图。
4. **探索**：节点式地图。
5. **任务 / 成就 / 设置 / 启动页**：排版收口。
6. 全程：动效与反馈（数字上浮、进度环、按压反馈、震动）。

## 五、与现有代码的映射（不要推翻已有系统）

| 界面 | 现有模块 | 要做的事 |
|---|---|---|
| 顶部资源栏 | `ui/shell.js` topbar + `Inventory` | 换成图标+数值，加时间/天气/设置入口 |
| 基地主视图 | `pages/Base.js`（已有建筑格+刻度）、`systems/Base.js` | 改成等距场景 + 详情卡 + 建造倒计时 |
| 背包 | `pages/Warehouse.js`、`systems/Inventory.js` | 网格化 + 容量条 + 分类页签 |
| 队伍 | `pages/Characters.js`、`systems/NPC/Crew` | 左列表右详情 + 属性和排班 |
| 探索 | `pages/Action.js`、`systems/Map.js` | 节点式地图（复用区域/道路/阻断数据） |
| 光脑 | `pages/Mind.js`、`systems/Tech.js` | 列表 → 科技树节点图 |
| 任务/成就 | `pages/Quest.js`、`pages/Achievement.js` | 进度条 + 奖励图标 + 前往 |
| 设置 | `pages/Settings.js` | 滑杆化 |

**硬约束**：所有状态变化仍必须经过 `core/effects.js` 的 `applyOutcome`；
不得为了好看而绕过结算、不得写死假数据、不得削弱测试。
