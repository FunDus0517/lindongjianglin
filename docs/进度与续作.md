## 三、部署与验证配方（每次发布照做）
1. 重建产物：`index.html` + `manifest.webmanifest` + `icon.svg` + `src/` → `D:\deepseek\winterfall-site`；
   `node tools/pack-bundle.mjs <stage> D:\deepseek\site-bundle.json` 生成 App 内容清单
2. 打包：site zip / project zip（PowerShell `ZipFile`），并复制到 `D:\GameViewer\Download\`
3. 推送：**必须走代理**（直连 github.com 不稳）：`git -c http.proxy=http://127.0.0.1:10808 push origin main`
4. 部署到 VPS（远程桌面）：
   - `cmdkey /generic:TERMSRV/59.153.167.60 /user:administrator /pass:<密码>`；`mstsc "D:\deepseek\winterfall-vps.rdp"`
   - **命令注入必须用键盘注入**（剪贴板常被 UU远程/Edge 占用）：
     `& D:\deepseek\rdp-key.ps1 -WinR -Text 'powershell -NoProfile -ExecutionPolicy Bypass -File \\tsclient\D\deepseek\deploy.ps1' -Enter`
   - 依次跑 `deploy.ps1`（同步 `C:\site`，并装 `Cache-Control: no-cache, must-revalidate`）与
     `publish-zip.ps1`（把 zip / 清单 / IPA / 交接文档复制到 `C:\site\download`）
5. 验证：外网 GET 关键文件、关键词命中、`Cache-Control` 头部、构建号；
   收尾必须 `Stop-Process mstsc` + `cmdkey /delete` 清干净
6. 构建号：`src/data/build.js` 的 `BUILD` 每次发布改成发布时间，界面会显示，用来确认版本
