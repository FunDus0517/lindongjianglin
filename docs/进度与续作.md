   - 收尾必须 `Stop-Process mstsc` + `cmdkey /delete:TERMSRV/...`（本轮已清干净）。



## 四、看图与自检（本轮更新，重要）
- **本会话的模型没有原生视觉**：`read_image` 只回一个附件 id，看图必须走视觉工具；
  而 **vision 描述类工具本轮被限流**（OVH 的 Qwen3.5-397B / Qwen2.5-VL-72B 全 RATE_LIMIT + 27B 超时），
  `modlens` 本机没配 provider，本地也没装 tesseract。所以本轮**没有真正"看"过用户的图**。
- **离线能用的三条取证通道**（本轮就是这么干的，别丢）：
  1. **Windows 自带 OCR**：`D:\deepseek\_winocr.ps1 -Path <图>`（`zh-Hans-CN`，离线，能读出参考图上的中文标注；
     本轮用它证明三张新图**一个字都没有** → 纯美术、不带 HUD）。
  2. **像素统计**：`D:\deepseek\img-map.ps1 -Path <图>`（区域字符图 + 亮度图），
     或直接 `System.Drawing` 扫行/列找色带边界（找面板、找分栏）。
  3. **渲染 + 条形码量尺**（本轮新建，UI 改动的客观自检闭环）：
     - `node D:\deepseek\dom-snapshot.mjs <输出html> [game|base|warehouse|action|characters|mind]`
       用测试同一套 DOM 垫片渲染**真实外壳 + 真实页面**并序列化成静态 HTML（`file://` 下 ES 模块被 CORS 挡，
       所以只能静态化；**记得序列化 `#app` 的子节点，别把 `#app` 自己再套一层**）。
     - 用 `vision_html_screenshot` 渲染（本机 Chrome/Edge **无法**从沙箱里直接起，exit code -2147483645；
       但这个工具可以）。
     - 同目录还会生成 `*-probe.html`：把真实 `getBoundingClientRect` / 栅格轨道编码成**像素条形码**
       （绿=值/100，黄=值%100），用 PowerShell 数像素解码 —— 因为 **OCR 读数字会把 `x` 和 `w` 读串**。
- 自检纪律：出稿后必须自己先看一遍再交给用户；本轮受限于视觉后端，改为"几何量尺 + OCR 校验"，
  并把三张稿子直接发给用户看。
